# ابدأ من هنا — Dragon S1

## أسرع طريقة للعرض

1. فك ضغط المشروع على جهاز السيرفر.
2. شغّل `run_server.bat`. سيُنشئ البيئة ويثبت المتطلبات ويشغّل السيرفر.
3. افتح `http://127.0.0.1:8000`.
4. سجل الدخول باسم `admin` وكلمة المرور `DragonS1@2026`.
5. على جهاز Windows آخر، عدّل `DRAGON_SERVER_URL` داخل ملف `.env` ليشير إلى IP السيرفر.
6. شغّل `run_agent.bat`.
7. اضغط **Simulate USB insertion**، اختر صورة بطاقة، واكتب الاسم والسبب.
8. ارجع للـ Dashboard واعمل Approve أو Reject.

## عرض بدون تشغيل الـ Agent

بعد تشغيل السيرفر اضغط `create_demo_request.bat` لإنشاء جهاز وطلب تجريبي بالصور المرفقة.

## مطابقة الوجه الحقيقية

الوضع الأساسي يحاول تشغيل DeepFace، ولو المكتبة غير موجودة يستخدم محرك تشابه صور مكتوب عليه بوضوح أنه Demo وليس تعرفًا بيومتريًا. لتثبيت DeepFace شغّل `install_deepface.bat`.

## التحكم الحقيقي في USB

متوقف افتراضيًا للأمان. للتجربة على جهاز مملوك لك فقط، شغّل الـ Agent كمسؤول واضبط `DRAGON_HARDWARE_USB_CONTROL=true`. قد تحتاج لفصل الفلاشة وإعادة توصيلها.
