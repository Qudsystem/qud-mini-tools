## 🎯 كيف تستخدمها؟

### 1️⃣ للحصول على PDF احترافي:
1. افتح `CV-Professional.html` بـ Chrome أو Edge.
2. اضغط **Ctrl + P** (طباعة).
3. اختر **Save as PDF**.
4. الإعدادات:
   - Paper: **A4**
   - Margins: **Default**
   - Background graphics: **✓ مفعّل**
5. اضغط **Save**.

### 2️⃣ لتعديل البيانات:
- افتح الملف بـ VS Code أو أي محرر نصوص.
- ابحث عن `أحمد محمد عبد الرحمن` واستبدله باسمك.
- عدّل الأقسام حسب خبرتك الفعلية.
